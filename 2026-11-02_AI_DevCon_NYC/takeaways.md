# Takeaways and Follow-up

Source: session notes, 17:00 Steve Yegge keynote, entry at 18:17:20.

## Takeaways

- Taste is the important piece.
- Engineering will recursively and iteratively solve the difficult technical problems.
- Conway's law: we will recreate human systems (org charts, status meetings, memos, communication paths) that feel comfortable to us because we need to debug them, even if they aren't best for AIs.
- We still don't have standards (emacs/vi, Visual Studio/JetBrains, LAMP). The interfaces are still being worked out.
- Context management is the new edge for managing complexity, now that code complexity and creation cost is almost $0.
- Because code generation is fast, the up-front and back-end human work (building the right product, and building the product right) can expand to do better.
